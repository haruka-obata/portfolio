職務経歴

ネットショップ運営会社（約9年）

  • 受発注・在庫管理・顧客対応などの業務を経験
  • Excel自動処理や手順書整備により、事務作業を標準化

システム開発研修（約3か月）

  • HTML / CSS / Java / JavaScript / Spring / OracleDB を習得
  • チーム開発にて基本設計〜テストまでの全工程を経験

金融系システム会社（約1年10か月）

  • Java・Shellによるバッチ処理・データ連携機能を構築
  • 要件定義〜結合テストまでを単独対応し、障害ゼロで納品
  • 設計書・連携仕様書を整備し、再利用性を向上

intra-mart案件（2025〜）

  • BloomMaker／LogicDesignerを用いた申請画面・ロジック構築
  • ER図作成・データモデリングを担当し、要件整理を効率化
  • 小規模チームで設計・テスト支援まで実施

主な開発実績

  • intra-mart申請管理システム構築
    使用技術：intra-mart（LogicDesigner／BloomMaker／ViewCreator）、JavaScript / PostgreSQL
    ロジック作成と設計書作成を担当し、申請業務の電子化を推進。
    プロジェクト規模（人数:約50名・期間:2025年8月～現在）
    担当フェーズ（設計・実装・テスト）
  • 金融系バッチ処理システム（COBOL／Shell）
    使用技術：COBOL、Shell、Oracle、Linux
    データ連携バッチを単独で開発。結合テストを含めた一連の開発を完遂。
    プロジェクト規模（人数:約120名・期間:2023年7月～2025年5月）
    担当フェーズ（要件定義・設計・実装・テスト）
  • GASによる社内自動化スクリプト
    使用技術：Google Apps Script、Spreadsheet API
    スプレッドシート入力内容を自動集計し、作業削減を実現。
  • ポートフォリオサイト制作
    使用技術：HTML / CSS / JavaScript
    レスポンシブ対応・軽量構成で自身のスキルと実績を紹介。

今後はGASを用いた業務自動化ツール開発にも注力し、 「仕組みで日常の手間を減らす」ことをテーマに活動予定です。
