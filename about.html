職務経歴

ネットショップ運営会社（約9年）

  • 受発注・在庫管理・顧客対応など、業務全体の効率化を担当
  • Excel自動処理や手順書整備など、事務プロセス改善を実施

システム開発研修（約3か月）

  • HTML / CSS / Java / JavaScript / Spring / OracleDB を習得
  • チーム開発で基本設計〜テストまでの一連工程を経験

金融系システム会社（約1年10か月）

  • Java・Shellを用いたバッチ処理・データ連携機能を構築
  • 要件定義〜結合テストまでを一人で対応し、障害ゼロで納品
  • 設計ドキュメント・データ連携仕様書を整備

intra-mart案件（2025年〜）

  • BloomMaker／LogicDesignerによる申請画面・ロジック構築
  • ER図作成・データモデリングを担当し、要件整理を効率化
  • 小規模チーム内で設計・テスト支援まで実施

主な開発実績

  • intra-mart申請管理システム構築
    使用技術：intra-mart（LogicDesigner／BloomMaker／ViewCreator）、JavaScript / PostgreSQL
    申請業務の電子化プロジェクトに参加。ロジック作成・設計書作成を担当。
  • 金融系バッチ処理システム（COBOL／Shell）
    使用技術：COBOL、Shell、Oracle、Linux
    データ連携バッチ開発を単独で担当。結合テストを含めた一連の開発を完遂。 処理性能を改善し、実行時間を30%短縮。
  • GASによる社内自動化スクリプト
    使用技術：Google Apps Script、Spreadsheet API
    スプレッドシート上で入力された内容を自動で整理・集計。 日次作業の自動化により担当者の作業時間を月10時間削減。
  • ポートフォリオサイト制作
    使用技術：HTML / CSS / JavaScript
    自身の実績・スキルを整理したWebサイトを自作。レスポンシブ対応・軽量構成を実現。

今後の展望

現在はintra-martを中心に業務システムの設計・開発を行っています。 今後はこれまでの経験を活かし、Google Apps Scriptを用いた業務自動化ツールの開発を目指しています。

「一度作った仕組みで、日常の手間を減らす」ことをテーマに、 シンプルで使いやすいシステムづくりに取り組んでいきます。
